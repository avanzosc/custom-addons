======================================
Inael Gestion de Fichajes - Produccion
======================================

* Tablas, campos, vistas y menus de los fichajes de fabrica (empleados que
  fichan, historico de fichajes y puestos para fichar).
* Solo consulta y edicion de los datos: de momento no incluye la operativa
  de fichar (entrada/salida, iniciar, comunicar o parar ordenes).


Bug Tracker
===========

Bugs are tracked on `GitHub Issues
<https://github.com/avanzosc/custom-addons/issues>`_. In case of trouble,
please check there if your issue has already been reported. If you spotted
it first, help us smash it by providing detailed and welcomed feedback.

Do not contact contributors directly about support or help with technical issues.
