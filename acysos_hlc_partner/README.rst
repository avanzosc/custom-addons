===========
HLC Partner
===========

This module adds HLC partner segmentation fields and reporting support.

Features
========

* Adds partner segments.
* Adds a segment field on contacts.
* Adds segment grouping on contact searches.
* Adds segment and current salesperson fields to the invoice report.
